# Laundrytrack

Build a modern, clean and professional web application called LaundryTrack – Laundry Management & Barcode Tracking System.

Create an initial responsive dashboard for a barcode-based laundry tracking system.

Include:

Dashboard with Total Orders, Received, In Process, Ready and Delivered statistics.

Recent Laundry Orders table.

Barcode ID, Customer Name, Items, Date and Laundry Status columns.

Search functionality for customers and barcode IDs.

Status filters.

Barcode lookup section where users can enter a barcode and view the laundry order details.

Order status workflow: Received → In Process → Ready → Delivered.

Sidebar navigation for Dashboard, Orders, Barcode Tracking, Customers and Reports.

Design:

Professional SaaS dashboard.

Navy blue and white colour palette.

Clean typography, rounded cards and subtle shadows.

Responsive desktop and mobile layout.

Use realistic sample data initially.

Keep the architecture modular so we can later integrate Supabase, authentication, actual barcode generation and camera-based barcode scanning.

For now, focus on creating a polished, functional frontend prototype. Do not overcomplicate the first version.
